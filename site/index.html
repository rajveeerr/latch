Why this exists

I always wanted Brave to have a native lock, like the one Safari has for private windows. It never shipped.

So I used a lock extension. It crashed my browser at random and lost my saved and grouped tabs more than once. That was the last straw.

I built the lock I wanted: fast like a native feature, light, secure, with the good features, and it never closes or touches a tab.

  1. Dec 2019First request for “a password for the browser itself” on the Brave Community forum.
  2. Nov 2024Brave opens issue #42457: password protection for tabs and profiles.
  3. 2026It is labelled P5: “not on the official roadmap.” A duplicate request is closed.
  4. NowLatch fills the gap, today, as an extension that stays out of your way.

What it does

Everything a lock should do, and nothing it shouldn't.

Locks instantly or on a timer
A shortcut, a button, after inactivity, in the background, on sleep or at startup.
Touch ID Beta
Unlock with Touch ID or a device passkey. Your passcode always works too.
Private windows, like Safari
Lock only your private windows and leave the rest of the browser open.
A recovery code
Forget your passcode and you do not have to remove the extension to get back in.
Know who tried
A private log of locks, unlocks and wrong guesses, kept on your computer only.
Covers, never closes
Pages are covered, media paused and tabs muted. Everything is put back exactly as it was.

How it stays safe for your tabs

Latch only covers things. A test fails the build if any code tries to close, reload, discard or navigate a tab.

  • No page contents read. No network. No accounts.
  • Fails open: if it cannot enforce the lock, it unlocks itself.
  • Remove it any time. Your tabs do not notice.

Install in a minute

Latch is not in a web store yet, so you load it as an unpacked extension. This is normal for new extensions.

A privacy lock, not a vault. It stops a passer-by, not an expert. Pair it with your computer's own lock.

  1. 1

    Download it

    Get the latest zip and unzip it somewhere permanent.

  2. 2

    Open the extensions page

    Paste brave://extensions in a tab and switch on Developer mode.

  3. 3

    Load it

    Click Load unpacked and choose the unzipped folder. Kerby will say hello.

Honest limits

Latch is a privacy lock for a browser you leave on a desk, not a security boundary. The install prompt will say it can read and change data on all sites. That is how any extension covers pages: a 5 KB script runs on every page to draw the cover. It reads nothing and sends nothing, and the code is open for you to check. It stops a casual passer-by, not someone with time and a terminal. Pair it with your computer's own lock: on a Mac press ⌃⌘Q, and keep a sign-in password on it. Touch ID is in beta and has not been tested on real hardware in Brave yet.
